# Security reporting

Please handle reports about authentication, account isolation, credentials, billing or hosted workloads privately.

If GitHub private vulnerability reporting is enabled for this repository, use the Security tab to submit a private report. Otherwise, request a private reporting channel from the project through its official account, [@latentagentsxyz](https://x.com/latentagentsxyz), before sharing sensitive technical details.

Public bug reports should include the affected feature, expected and observed behavior, and a minimal description with credentials and private data removed. Avoid posting access tokens, session cookies, wallet keys, payment details, personal data or production configuration.
