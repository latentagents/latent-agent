# Changelog

Product changes recorded from the Latent Agent source releases. Live availability is determined by the hosted installation and its integration configuration.

## 0.2.13 — 2026-11-20

- Recent work is placed above workspace tools, with quick search, expandable conversation history and an anchored account footer.
- Responsive navigation and activity drawers avoid narrowing the chat panel on phones and tablets. Pending approvals remain visible from the conversation.
- Added an adaptive, keyboard-aware composer, responsive dashboard layouts, and batched model directory rendering with full-catalog search.

## 0.2.12 — 2026-11-20

- Added support for InferHub marketplace ask ranges and correctly classified vision-capable chat models.
- Hosted marketplace requests use explicit maximum unit-price bids, and usage settlement uses the reported provider cost when available.
- Simplified the homepage hero; launch eligibility remains visible in signup and referral sections.

## 0.2.11 — 2026-11-20

- Added verified email linking for existing Privy wallet accounts without changing their workspace or balance.
- Organic eligible signup credit remains $5; new eligible referred signups receive $8 and inviters receive $2, subject to campaign limits.
- Added an authenticated InferHub model catalog sync, searchable directory, provider brand marks, and verified pricing. Non-chat models are shown separately; unverified rates cannot be used for credit-funded runs.

## 0.2.10 — 2026-11-19

- Corrected the public client fetch receiver for browser usage and rendered reviewed execution records directly in page HTML.
- Added $5 signup and $2 referral credit for eligible new verified accounts, with server-enforced campaign caps and credit-ledger accounting. Live availability depends on the hosted configuration.
- Updated public navigation with GitHub and X brand marks.

## 0.2.9 — 2026-11-19

- Added public database and worker-heartbeat status.
- Added a public demo page and review-before-publish execution receipts containing actual run output and metered usage.
- Added temporary read-only API trial keys and the shared JavaScript client.
- Connected the website, documentation, repository and official X profile.

## 0.2.8 — 2026-11-18

- Expanded website developer documentation and API examples for JavaScript, cURL and CLI usage.
- Added desktop Coming-soon and changelog pages.
- Updated public navigation and the animated contour presentation.
- Improved responsive presentation and code-copy interactions in the documentation.

## Earlier 0.2.x updates — November 2026

- Added the Latent monochrome visual identity and shared logo assets.
- Added same-domain application subdomain routing with the primary hostname reserved for the workspace.
- Integrated Privy wallet, Google and email authentication.
- Improved deployment setup validation and HTTPS setup documentation.

## Existing platform foundations

- Multi-agent conversations, persistent workspace artifacts and cloud task execution.
- Deployment lifecycle controls, scheduled tasks and ordered workflows.
- Scoped developer API, model-provider support and credit accounting.
