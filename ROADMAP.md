# Roadmap

Latent's near-term direction is to improve the browser-based agent and cloud experience. Items are grouped by intended scope, without promised release dates.

## Core experience

- Cloud task execution and saved results.
- Agent instructions, memory and project conversations.
- Application hosting, service lifecycle and logs.
- Budget controls, scoped API keys and model selection.
- Public status, reviewed execution receipts and limited API trials (implemented in 0.2.9; hosted activation and the first publication are separate checks).

## Integration and operational work

- Validate the hosted sign-in and end-to-end build/deploy flow.
- Exercise GitHub and MCP integrations with configured accounts.
- Complete provider-specific checks for wallet, credit and media adapters.
- Improve operational observability, reliability and recovery.
