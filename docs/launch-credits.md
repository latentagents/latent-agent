# Launch welcome credit and referrals

The 0.2.10 hosted workspace supports $5 in promotional workspace credits for eligible new accounts created using verified Privy email/Google login. A valid referral from an existing verified member adds a $2 reward to the inviter's credit ledger. The referred account still receives $5, not $7.

Open [Latent workspace](https://latentagents.xyz/app), then the **Referrals** view to create and copy a personal invite link. New members may open that link or enter the code before their first verified sign-in. One verified account may claim one signup grant. Duplicate email identities and self-referrals are not eligible for repeated rewards. Wallet-only login is supported but does not qualify for launch rewards.

Credits are usable within Latent, not withdrawable cash. The campaign has daily and overall allocations, and pending eligible claims retry on subsequent verified sign-in. Live availability depends on the hosted configuration. These rewards are not granted through public read-only API keys.

View the real execution record at [Public demo](https://latentagents.xyz/demo), check [system status](https://latentagents.xyz/status), and review the [service information](https://latentagents.xyz/legal).
