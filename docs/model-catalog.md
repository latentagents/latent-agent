# Hosted models and costs

Explore the live [model directory](https://latentagents.xyz/models) or search the Models view in the workspace. The hosted installation synchronizes the InferHub catalog permitted by its inference key. Market ask ranges are shown in USD/USDC per million input and output tokens. Requests use the displayed upper bound as an explicit price cap; the reported provider cost is used to settle actual credit charges when available. A minimum ask is not a guaranteed routed price. The model selector displays locally served brand icons and exact routing IDs.

Chat models with confirmed prices are selectable. Media and embedding catalog entries have different endpoint requirements and are listed separately, rather than being represented as runnable chat models. Models with unknown or stale rates cannot be selected for new credit-funded runs. Catalog availability and rates may change with upstream configuration.

The directory starts with available chat models. Matching hosted model suffixes and modalities share a card; expand its routes to compare individual provider IDs, current price ranges and readiness. Choosing a route still selects its exact provider ID. Distinct model versions and user-configured providers are not merged.

The existing scoped developer API lists enabled model choices. Public trial keys remain read-only. Logos are from the MIT-licensed [Lobe Icons project](https://github.com/lobehub/lobe-icons); brands belong to their respective owners.
